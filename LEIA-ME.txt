SISTEMA DE FILMES - SEMINÁRIO TECWEB

Tecnologias
- Java 21
- Spring Boot
- Spring Data JPA
- Thymeleaf
- Banco H2

Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta filmes no VS Code.
3. Aguarde o Maven carregar as dependências.
4. Execute FilmesApplication.java ou use ./mvnw spring-boot:run.
5. Acesse http://localhost:8080.

O sistema possui cadastros de filmes, categorias, diretores e produtoras. O painel inicial apresenta os totais cadastrados e a média das notas dos filmes. Os filmes possuem relacionamentos com categoria, diretor e produtora.

Observação: o banco H2 está configurado em memória. Os dados são reiniciados quando a aplicação é encerrada.
